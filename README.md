## 🤖 싱글 모드 · AI 채팅 서비스 분리

싱글 모드를 추가했습니다. AI 수덕과 1:1로 한국어 대화를 나누고, 대화가 끝나면 그 내용으로 쉐도잉 문장을 만듭니다.

AI 채팅은 메시지 한 건마다 OpenAI 응답을 1초 안팎 기다립니다. 기존 서버(Tomcat) 구조에서는 이 시간 동안 스레드를 붙잡고 있어, 사용자가 늘면 AI와 무관한 API까지 함께 느려집니다. 그래서 AI 채팅 API만 Spring WebFlux 서비스([`ai-chat/`](ai-chat/))로 분리했습니다. 기존 서버와 같은 API 경로, Redis 키, JWT 비밀키를 쓰며, 운영에서는 Nginx가 `/api/v1/ai-chat/*`만 이 서비스로 보내도록 구성합니다([포팅 매뉴얼 3.7](exec/%ED%8F%AC%ED%8C%85%EB%A9%94%EB%89%B4%EC%96%BC.md)).

같은 자원(2 vCPU / 1.5GB)과 같은 부하 시나리오로 비교했을 때, 동시 100명 기준 첫 응답 p95는 16.2초에서 0.71초로, 800명 구간 JVM 스레드는 233개에서 21개로 줄었습니다. 측정 방법과 해석, 한계는 [bench/README.md](bench/README.md)에 정리했습니다.
